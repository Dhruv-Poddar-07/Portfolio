## ✨ Features

- 🎨 Glassmorphism design with custom color theming
- 📱 Fully responsive — mobile menu included
- 🎭 Smooth scroll-triggered animations
- 🖱️ Interactive project cards with hover reveals
- 📬 Built-in contact form


## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Framework | React + Vite |
| Styling | Tailwind CSS v4 |
| Icons | Custom SVGs + Lucide React |
| Deployment | Vercel |

## 🚀 Getting Started

```bash
git clone https://github.com/Dhruv-Poddar-07/Portfolio.git
cd Portfolio
npm install
npm run dev
```
