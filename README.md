# Portfolio

My personal developer portfolio — built with React, Vite, and Tailwind CSS.

## Sections

- **Hero** — intro, skills marquee, social links
- **About** — background and what I do
- **Projects** — featured work with live demo + GitHub links
- **Experience** — timeline of learning/work
- **Testimonials** — feedback
- **Contact** — get in touch form

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- Lucide React (icons)
